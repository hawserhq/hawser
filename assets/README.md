# Hawser identity

A coiled heavy rope — a hawser is the thick line that moors a ship, and Hawser
is the line that moors stock `docker.exe` to the engine.

| file | use |
|---|---|
| `hawser-mark.svg` | the color mark (slate rope with twist grooves) |
| `hawser-mark-mono.svg` | monochrome silhouette; inherits `currentColor`, for docs / badges / terminals |
| `hawser-logo.svg` | horizontal lockup: mark + `hawser` wordmark |

## Design notes

- One Archimedean-spiral path with a heavy round stroke — pure geometry, no
  fonts and no rasterizer, so it scales exactly from a 16 px tray dot to a
  512 px store tile and the small sizes stay legible (the coil reads as a dense
  spiral-disc when tiny, showing its grooves only as it grows).
- The color mark's twist grooves are a translucent-black overlay, so the rope
  re-colors to any brand hue by changing one value — the grooves follow.
- Deliberately clear of Docker's whale / Moby and the other container-tool
  marks: a rope, nothing else.

## Raster assets (`icons/`)

The SVG is the master; the rasters below are generated from the same spiral in
pure Go (`tools/genicons`), no external rasterizer:

| file | use |
|---|---|
| `icons/hawser.ico` | multi-size (16–256) Windows icon, embedded in the `.exe`s |
| `icons/favicon-32.png` | docs-site favicon |
| `icons/hawser-256.png`, `-512.png` | general raster use |
| `icons/social-preview.png` | 1280×640 GitHub social preview (upload in repo Settings) |

The tray status icons (`cmd/hawsertray/icons_windows.go`) are the mark tinted to
the engine state — green (running) / grey (idle) / red (down) — generated by the
same tool.

The icon is embedded into `hawser.exe`, `hawserw.exe` and `hawsertray.exe` via
per-arch `rsrc_windows_{amd64,arm64}.syso` resource files in each `cmd/` dir, so
a plain `go build` carries it — no workflow change needed.

## Regenerate

```
go run ./tools/genlogo    # rewrites the SVG masters
go run ./tools/genicons   # rewrites icons/ and the tray icons

# the embedded-executable .syso (needs the rsrc tool, fetched on demand):
for d in cmd/hawser cmd/hawserw cmd/hawsertray; do
  for a in amd64 arm64; do
    go run github.com/akavel/rsrc@v0.10.2 -ico assets/icons/hawser.ico -arch $a -o $d/rsrc_windows_$a.syso
  done
done
```

The rope color is the `brand` constant in `tools/genlogo` and `tools/genicons`.
